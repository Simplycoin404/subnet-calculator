# Subnet Calculator

This is a beginner Python subnet calculator created while learning networking and CCNA concepts.

## Features

- Calculates total addresses
- Calculates usable hosts
- Displays subnet masks
- Uses CIDR notation

## Example

```txt
Enter CIDR number: 24

CIDR: /24
Subnet Mask: 255.255.255.0
Total Addresses: 256
Usable Hosts: 254
```
